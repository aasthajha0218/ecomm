# InnovoCommerce — Enterprise Landing Page

Simple, responsive e‑commerce landing page built with vanilla HTML, CSS, and JS.

Files added:
- [index.html](index.html)
- [styles.css](styles.css)
- [scripts.js](scripts.js)

Open `index.html` in your browser to preview. No build steps required.

Optional: Serve locally with a static server for best results:

```
# Python 3
python -m http.server 8000

# Node (if http-server installed)
npx http-server -c-1
```
